# Signature images

Add each signature using the corresponding base filename:

- `julius-bethge`
- `gaspar-harmati`
- `mohsin-saeed`
- `marco-fabian-schroeder`
- `sebastian-straub`

Supported formats are PNG, JPG, JPEG, and PDF, using lowercase file extensions. For example, `julius-bethge.png`.

The report automatically places each available image above that author's signature line on the declaration page. A transparent PNG cropped closely around the signature generally produces the best result.
