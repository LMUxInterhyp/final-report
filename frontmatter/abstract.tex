\section*{Abstract}

Interhyp's internal multi-agent chatbot relies on a Router to assign each user query to the appropriate specialist agent. Because routing errors had previously been identified and corrected through manual feedback analysis and prompt refinement, this project developed a reproducible pipeline for evaluating and improving Router decisions. Built over five Scrum sprints, the solution combines a similarity-based first routing stage, a large language model (LLM)-based second stage, an LLM judge, and an OPRO-based prompt optimizer in a working showcase application with evaluation, training, and optimization dashboards.

The pipeline was evaluated in a structurally comparable real-estate scenario using synthetic data, with 1,000 training queries kept separate from a fixed set of 240 evaluation queries. Optimizing only the Stage 2 prompt increased held-out routing accuracy from 83\% to 100\%. The complete two-stage Router achieved 98\% accuracy while Stage 1 resolved 78\% of queries directly, avoiding 188 Stage 2 LLM calls and reducing average latency from 669 ms to 407 ms, or 39\%. The judge reached 99\% agreement with ground truth in a separate evaluation, although judge-based and golden-label measurements differed in the optimization experiment.

These results show that automated judge feedback can support measurable routing improvements and that selective similarity-based routing can reduce latency and model use while retaining most accuracy gains. However, validation on independently labelled production data and periodic human calibration of the judge remain necessary before deployment.
